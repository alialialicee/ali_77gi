# 칠일금기

사용자의 이름, 생년월일, 태어난 시간, 성별을 바탕으로 앞으로 일주일 동안 “피해야 할 것”만 보여주는 모바일 우선 오컬트 금기 문서 웹앱입니다. 일반적인 좋은 운세가 아니라 저주받은 기록, 봉인된 예언문, 검붉은 부적 문서 같은 분위기를 목표로 합니다.

## 기술 스택

- React
- TypeScript
- Vite
- CSS

## 설치 방법

```bash
npm install
```

## 실행 방법

```bash
npm run dev
```

## 빌드 방법

```bash
npm run build
```

## 동작 방식

- 외부 API를 사용하지 않습니다.
- 외부 이미지, CDN, 외부 폰트를 사용하지 않습니다.
- 모든 시각 요소는 HTML과 CSS로 표현합니다.
- 입력값은 서버로 전송하지 않으며, 브라우저 화면에서 결과를 생성하는 용도로만 사용합니다.
- 요일별 금기는 seed 기반으로 시간대, 장소, 사람, 물건, 행동, 문장 템플릿을 독립 선택해 7일 내내 같은 조건이 반복되지 않도록 보정합니다.

## Capacitor 메모

최종 목표는 이 Vite 웹앱을 추후 Capacitor로 Android 앱으로 감싸 Google Play Store에 등록할 수 있게 준비하는 것입니다. 현재는 웹앱으로 바로 실행 가능한 상태입니다.
